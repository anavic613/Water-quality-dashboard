# 💧 Water Quality & Compliance Dashboard

## 📋 Overview
This project is an interactive web-based dashboard developed to monitor and analyze water quality parameters (**pH, Turbidity, and Bacteriological Status**) across different collection stations. 
It bridges environmental laboratory routines (aligned with **Good Laboratory Practices - GLP** and **SOPs**) with modern data science and software development tools.

## 🚀 Features
* **Interactive Filtering:** Filter data by specific monitoring stations and timeframes.
* **Real-time Metrics:** Automatic calculation of key statistics (average pH, turbidity levels, and sample counts).
* **Compliance Thresholds:** Visual indicators highlighting regulatory limits for water safety.
* **Data Traceability:** Clean tabular views simulating laboratory database records.

## 🛠️ Technologies Used
* **Python** (Core logic and data manipulation)
* **Streamlit** (Web app framework and dashboard UI)
* **Pandas & NumPy** (Data processing)
* **Plotly** (Interactive data visualization)
